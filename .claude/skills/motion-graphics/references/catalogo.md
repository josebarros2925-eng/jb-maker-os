# Catálogo de direções e efeitos

Este índice ajuda a conversar sobre intenção. Os dez modelos abaixo têm guias próprios com perguntas, mecânica, preparação e revisão. São instruções autorais informadas pelo estudo da biblioteca citada em [ATTRIBUTION.md](../ATTRIBUTION.md), não cópias dos prompts ou resultados comprovados. Aqui, “modelo” significa uma direção criativa, não um modelo de IA.

## Encontrar a direção pelo objetivo

| O aluno quer… | Possibilidades para oferecer conforme o conteúdo |
|---|---|
| Apresentar produto técnico | Produto explodido para componentes; objeto com volume para acabamento externo; filmagem com gráficos para demonstrar uso. |
| Valorizar alimento, bebida ou cosmético | Montagem dinâmica para ingredientes; produto tropical para sensação de ambiente; objeto com volume para embalagem. Verificar ingredientes e contexto antes de sugerir. |
| Lançar aplicativo ou serviço | Interface de vidro para processo e resultado; tipografia para promessa curta; explicação vetorial para situações de uso. |
| Explicar uma ideia, aula ou instituição | Colagem para relações visuais; vetorial para jornada; híbrido 2D + 3D para interação entre personagens e objetos. |
| Apresentar arquitetura | Planta virando construção, quando há coerência entre desenho e volume. |
| Trabalhar com vídeo existente | Filmagem com gráficos; perguntar o que deve permanecer preservado. |
| Mostrar números ou evolução | Dados animados; definir fonte, escala e comparação. |

Ofereça duas ou três opções pertinentes e pergunte qual interessa. A escolha pertence ao aluno. Se já houver referência ou efeito definido, siga essa direção sem refazer a seleção. Se nenhuma opção servir, desenvolva uma direção própria. Consulte apenas os guias escolhidos, antes de preparar prompt/código/geração; siga [como usar](modelos/como-usar.md).

## Outras direções já disponíveis

- **Objeto com volume:** abertura de livro, articulação, giro ou detalhes externos. Consulte [Objetos 3D](tecnicas.md#objetos-3d). Um giro de embalagem não precisa revelar seu interior.
- **Dados animados:** linhas, marcadores e rótulos coordenados. Consulte [direção](direcao-e-movimento.md) e [revisão](revisao-e-entrega.md). Valores e escalas precisam concordar durante a animação.

A [galeria local](../assets/galeria.html) oferece esquemas estáticos e prepara um pedido, sem gerar mídia ou enviar dados. Não é necessário abrir a galeria para usar o catálogo no chat.

Uma combinação tem uma direção dominante e uma função definida para cada efeito auxiliar. Adapte formato, ritmo, estilo e quantidade de ações ao briefing. Não transforme a lista em um vídeo que acumula todos os efeitos.
